# v0.1.2 — Office que no responde al iniciar

## Correcciones

- **Word y PowerPoint**: la conversión podía fallar de forma intermitente con
  «Error en la ejecución de servidor» (`CO_E_SERVER_EXEC_FAILURE`, 0x80080005). Esto pasa cuando la
  aplicación de Office se queda colgada al iniciarse. Ahora la herramienta cierra la instancia colgada
  que ella misma lanzó y lo intenta una vez más. Una instancia que usted ya tenía abierta no se toca.
  Si vuelve a fallar, el mensaje indica qué hacer: abrir el documento a mano para revisar si Office
  tiene un aviso pendiente.

## Novedades

- Cada fallo de conversión queda anotado en `%LOCALAPPDATA%\NativeOfficeToPdf\errores.log`, con
  hora, versión, archivo, código de error y mensaje. Sirve para diagnosticar un fallo después de que
  ocurrió.

## Notas de actualización

- El instalador reemplaza la versión anterior sin desinstalarla primero.
